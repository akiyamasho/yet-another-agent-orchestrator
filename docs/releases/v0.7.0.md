# Constellation v0.7.0

## Highlights

- Adds review-gated automatic integration for exact worker commits from Constellation-owned Git worktrees.
- Serializes integrations with a tokenized lock, preserves project and conflict data, retains source branches, and records merge, completion, and parent-completion results.
- Adds conservative restart reconciliation and Inspector controls for retrying review or integration and cleaning up a verified worktree.
- Makes review, integration, commit, conflict, and cleanup outcomes visible in the Inspector. Root mode remains unchanged.

## Safety

- Automatic cleanup is limited to verified-clean, deterministic worktrees owned by Constellation and does not use force cleanup.
- Recovery IPC accepts only a validated run ID; the main process resolves the registered project root and does not accept renderer-supplied filesystem paths.
- Integration and recovery never use Git reset, clean, stash, abort, or force cleanup. Conflicts and working data are preserved for manual attention.

## Verification

- TypeScript typechecking and repository diff validation were run for this release metadata update.
- Provider and orchestration behavior remains covered by the project’s existing test suite; no test count is claimed here.
