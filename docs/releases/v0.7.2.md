# Constellation v0.7.2

## Highlights

- Adds a secure integrated terminal for each root Codex or Claude Code agent, running commands in that agent's registered project folder.
- Adds an `Open folder` action that opens a root agent's project folder in Finder.
- Keeps terminal execution scoped to canonical, registered project roots and cleans up active runs when the window closes.

## Verification

- TypeScript checks, provider/orchestration tests, production build, Electron launch, and packaged artifact checks were run for this release.
- Release screenshots use browser demo mode and synthetic fixtures only.
