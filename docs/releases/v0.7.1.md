# Constellation v0.7.1

## Highlights

- Adds a compact Usage Remaining meter to the status bar with click-to-open Codex and Claude Code usage details.
- Improves Codex main-agent creation so newly created threads remain available while the provider inventory catches up.
- Keeps provider health and usage state explicit, with clear unavailable and refresh states when a provider cannot report limits.

## Verification

- TypeScript checks, provider/orchestration tests, production build, Electron launch, and packaged artifact checks were run for this release.
- Release screenshots use browser demo mode and synthetic fixtures only.
